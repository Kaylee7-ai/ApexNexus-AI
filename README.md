# 🛡️ ApexNexus AI

ApexNexus is an AI-powered defensive cybersecurity operations assistant.

It is designed to help security teams and students understand security
problems, investigate defensive evidence and receive practical remediation
guidance.

## Features

- Natural-language cybersecurity assistant
- Website security posture checks
- Static code-security analysis
- Security log analysis
- Cloud/IAM security review
- Threat-indicator classification
- Incident-response guidance
- Vulnerability remediation guidance
- Streamlit dashboard
- Defensive and evidence-based behavior
